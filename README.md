# Create-Stranded-at-Sea-Ru

Информация: Перевод квестов в сборке Create: Stranded at Sea (3.10) Ссылка на [сборку](https://www.curseforge.com/minecraft/modpacks/create-stranded-at-sea)

Установка: Пример для Prism Launcher:

Скопировать с заменой файлы в корневую директорию сборки. Например, C:\Users\user\AppData\Roaming\PrismLauncher\instances\CSaS\minecraft

После запустите игру и проверьте работу перевода.

Если найдёте какие-то ошибки, можете сообщить о них мне в дискорд:narik_20

Для перевода модов использовал:

[RTF Extension](https://modrinth.com/resourcepack/rtf-extension)
